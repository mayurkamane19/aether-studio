# Aether Studio — International Creative Agency & Visual Engineering Platform

Production-ready, deployment-grade creative agency portfolio featuring 4 complete master case studies (**AURA MONOLITH™**, **NOVA COFFEE™**, **LUXE INTERIORS™**, **NEURA AI™**).

## 🚀 Key Features
- **4 Master Case Studies**: End-to-end visual identity, 3D archviz, packaging, and enterprise AI SaaS design systems.
- **Apple & Linear Motion System**: GSAP + Lenis smooth scroll ticker with zero layout shifts.
- **PWA Capabilities**: Service Worker (`sw.js`) network-first offline caching and `manifest.json`.
- **Keyboard Shortcuts**: `Cmd/Ctrl + K` or `/` for global search, `Esc` to close overlays, `Left/Right` arrow keys for modal case study navigation.
- **SEO & Social Metadata**: OpenGraph, Twitter Cards, and `Schema.org` JSON-LD Organization markup.

## 🛠 Tech Stack
- **HTML5 & CSS3**: Vanilla dark mode design system (`#06070a`), glassmorphic panels, and fluid 8pt grid typography.
- **JavaScript (ES6+)**: Custom SPA modal routing, automated showcase carousel, and CMS search engine.
- **Libraries**: GSAP 3.12, ScrollTrigger, Lenis 1.1, Lucide Icons.
