# 🚀 Aether Studio

> **International Creative Agency & Visual Engineering Platform**

A production-ready premium creative agency portfolio showcasing high-end branding, UI/UX, visual engineering, architectural visualization, and enterprise AI product design. Built with modern HTML, CSS, and JavaScript, featuring smooth animations, responsive layouts, and a premium user experience.

🌐 **Live Website:** https://aether-studio-pi.vercel.app

📂 **GitHub Repository:** https://github.com/mayurkamane19/aether-studio

---

## ✨ Features

- 🎨 Premium International Creative Agency Design
- 📱 Fully Responsive (Desktop, Tablet & Mobile)
- 🌙 Dark Premium UI with Glassmorphism
- 🚀 High Performance & Fast Loading
- 🎬 Cinematic Hero Showcase
- 💼 Interactive Portfolio Showcase
- 🎯 Proposal Wizard
- 📅 Consultation Booking Experience
- 🔍 Global Search
- 🎭 Smooth GSAP Animations
- ⚡ Lenis Smooth Scrolling
- 🖼 Premium Image Gallery
- 📊 Interactive Statistics Cards
- 📞 Contact & Consultation Section
- ♿ Accessibility Friendly
- 🔎 SEO Optimized
- 📲 Progressive Web App (PWA) Ready
